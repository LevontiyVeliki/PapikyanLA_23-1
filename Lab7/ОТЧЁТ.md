Теоретическая часть
Основные понятия
Куча (Heap) - специализированная древовидная структура данных, удовлетворяющая свойству кучи. Является полным бинарным деревом (все уровни заполнены, кроме последнего, который заполняется слева направо).

Свойство кучи:
Min-Heap: Значение в любом узле меньше или равно значениям его потомков. Корень - минимальный элемент.
Max-Heap: Значение в любом узле больше или равно значениям его потомков. Корень - максимальный элемент.

Реализация на основе массива
Куча эффективно реализуется на основе массива. Для узла с индексом i:

Индекс родителя: (i-1)//2
Индекс левого потомка: 2*i + 1
Индекс правого потомка: 2*i + 2

Ключевые особенности реализации
MinHeap класс - минимальная куча с методами:
insert() - вставка элемента
extract() - извлечение минимального элемента
build_heap() - построение кучи из массива
_sift_up() - всплытие элемента
_sift_down() - погружение элемента
visualize() - текстовая визуализация
MaxHeap класс - максимальная куча с аналогичным интерфейсом

Алгоритмы сортировки:
heapsort_using_minheap() - с использованием min-кучи
heapsort_using_maxheap() - с использованием max-кучи
heapsort_inplace() - in-place версия без дополнительной памяти
PriorityQueue класс - приоритетная очередь на основе min-кучи

Сравнение алгоритмов сортировки
Heapsort демонстрирует стабильную производительность O(n log n)
Quicksort обычно быстрее на случайных данных благодаря меньшей константе
Mergesort показывает схожие с Heapsort результаты
Built-in sort (Timsort) значительно эффективнее благодаря оптимизациям

Ключевые выводы
Build Heap эффективнее последовательной вставки для построения кучи из массива
Heapsort гарантирует O(n log n) в худшем случае, в отличие от Quicksort
In-place Heapsort экономит память, но работает немного медленнее
Приоритетная очередь на основе кучи эффективно поддерживает операции вставки и извлечения за O(log n)

Ответы на контрольные вопросы
1. Основное свойство min-кучи и max-кучи
Min-Heap: Значение в любом узле меньше или равно значениям его потомков. Корень содержит минимальный элемент.
Max-Heap: Значение в любом узле больше или равно значениям его потомков. Корень содержит максимальный элемент.

2. Алгоритм операции вставки нового элемента в кучу
Процедура sift_up:
Добавить элемент в конец массива (последняя позиция в полном бинарном дереве)
Сравнить с родителем
Если нарушено свойство кучи, поменять местами с родителем
Повторять шаги 2-3 до восстановления свойства кучи или достижения корня

3. Временная сложность построения кучи из произвольного массива
Сложность O(n) достигается благодаря алгоритму heapify:
Начинаем с последнего нелистового узла (индекс n/2 - 1)
Применяем sift_down для каждого узла снизу вверх
Большинство узлов находятся near the bottom и требуют мало операций
Математический анализ показывает сумму высот O(n)

4. Алгоритм пирамидальной сортировки (Heapsort)
Построить max-кучу из исходного массива
Найти максимальный элемент (корень) и поменять его с последним элементом
Уменьшить размер кучи на 1 и применить sift_down к корню
Повторять шаги 2-3 пока куча не пуста
В результате массив отсортирован по возрастанию

5. Применение кучи для приоритетной очереди
Кучу используют потому что она эффективно поддерживает:
Вставка за O(log n)
Извлечение минимального/максимального за O(log n)
Просмотр корня за O(1)
