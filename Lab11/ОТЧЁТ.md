Теоретическая часть
Основные понятия
Префикс-функция - для строки S длиной n представляет собой массив π[0..n-1], где π[i] - длина наибольшего собственного префикса, который является суффиксом подстроки S[0..i].
Z-функция - для строки S длиной n представляет собой массив z[0..n-1], где z[i] - длина наибольшего общего префикса строки S и суффикса S[i..n-1].

Алгоритмы поиска подстрок
Алгоритм Кнута-Морриса-Пратта (KMP): O(n + m), использует префикс-функцию

Z-алгоритм: O(n + m), использует Z-функцию
Алгоритм Бойера-Мура: O(n/m) в лучшем случае, O(n*m) в худшем
Алгоритм Рабина-Карпа: O(n + m) в среднем, O(n*m) в худшем

Ответы на контрольные вопросы
1. Префикс-функция и её использование в KMP
Префикс-функция π[i] - длина наибольшего собственного префикса, который является суффиксом подстроки S[0..i].
В KMP префикс-функция используется для определения максимального сдвига паттерна при несовпадении символов, что позволяет избежать возвратов в тексте и достичь сложности O(n + m).

2. Преимущество KMP перед наивным алгоритмом
Пример: Текст "aaa...a" (1000 символов), паттерн "aaa...b" (500 символов)
Наивный алгоритм: O(n*m) = 1000×500 сравнений
KMP: O(n + m) = 1000 + 500 операций
KMP избегает повторных сравнений уже проверенных символов.

3. Z-функция и поиск подстрок
Z-функция z[i] - длина наибольшего общего префикса строки S и суффикса S[i..n-1].

Для поиска подстрок: Создаем строку "pattern$text", вычисляем Z-функцию. Позиции, где z[i] = len(pattern), соответствуют вхождениям паттерна.

4. Алгоритм Бойера-Мура
Идея: Сравнивать паттерн с текстом справа налево, использовать эвристики для больших сдвигов.

Эвристики:
Плохой символ: Сдвиг на основе последнего несовпавшего символа текста
Хороший суффикс: Сдвиг на основе совпавшего суффикса

5. Дополнительные применения префикс- и Z-функций
Поиск периода строки: period = n - π[n-1]
Подсчет различных подстрок: Сумма (i - max_z) для всех префиксов
Поиск палиндромов: Анализ симметрии
Сжатие данных: Выявление повторяющихся паттернов
