Лабораторная работа №9: Динамическое программирование
Цель работы
Изучение метода динамического программирования (ДП) как мощного инструмента для решения сложных задач путём их разбиения на перекрывающиеся подзадачи. Освоение двух основных подхода к реализации ДП: нисходящий (с мемоизацией) и восходящий (с заполнением таблицы). Получение практических навыков выявления оптимальной подструктуры задач, построения таблиц ДП и анализа временной и пространственной сложности алгоритмов.

Теоретическая часть

Основные понятия
Динамическое программирование (ДП) - метод решения задач, в которых оптимальное решение всей задачи зависит от оптимальных решений её перекрывающихся подзадач.

Ключевые принципы:

Оптимальная подструктура: Оптимальное решение задачи может быть построено из оптимальных решений её подзадач.
Перекрывающиеся подзадачи: Подзадачи, решения которых используются многократно, а не один раз.

Подходы к реализации
Нисходящее ДП (Top-Down, с мемоизацией): Рекурсивное решение с сохранением (кэшированием) результатов решения подзадач для повторных вычислений.
Восходящее ДП (Bottom-Up, табличное): Итеративное решение, при котором подзадачи решаются от простейших к сложным, а их результаты заносятся в таблицу (массив).

Реализованные алгоритмы
Числа Фибоначчи - 5 различных реализаций

Задача о рюкзаке 0-1 - восходящий и нисходящий подходы
Наибольшая общая подпоследовательность (LCS) - с восстановлением решения
Расстояние Левенштейна - редакционное расстояние
Задача о размене монет - минимальное количество и количество способов
Наибольшая возрастающая подпоследовательность (LIS) - O(n²) и O(n log n)

Оптимизация использования памяти
Рюкзак 0-1: От O(n·W) до O(W) с использованием одного массива
LCS: От O(m·n) до O(min(m,n)) с чередованием массивов
Фибоначчи: От O(n) до O(1) с хранением только двух предыдущих значений

Ключевые выводы
ДП эффективно для задач с оптимальной подструктурой и перекрывающимися подзадачами
Восходящий подход обычно эффективнее по памяти из-за отсутствия рекурсии
Мемоизация проще в реализации и более читаема
Оптимизация памяти возможна для многих классических задач ДП
Восстановление решения требует дополнительной памяти для хранения обратных ссылок

Ответы на контрольные вопросы
1. Свойства задачи для применения ДП
Два основных свойства:
Оптимальная подструктура - оптимальное решение задачи содержит оптимальные решения подзадач
Перекрывающиеся подзадачи - подзадачи решаются многократно

2. Разница между нисходящим и восходящим подходами
Нисходящий (Top-Down):
Рекурсивный подход с мемоизацией
Решает только необходимые подзадачи
Может быть неэффективен по памяти из-за стека вызовов
Восходящий (Bottom-Up):
Итеративный подход с заполнением таблицы
Решает все подзадачи от простых к сложным
Обычно более эффективен по памяти

3. Оптимальная подструктура в задаче о рюкзаке
Для рюкзака 0-1 оптимальное решение для i предметов и вместимости w можно построить из двух случаев:
Не брать i-й предмет → решение для i-1 предметов и вместимости w
Взять i-й предмет → стоимость i-го предмета + решение для i-1 предметов и вместимости w - weight[i]

4. Построение таблицы для LCS
Таблица dp[i][j] хранит длину LCS для префиксов x[0..i-1] и y[0..j-1]:
Инициализация: dp[0][j] = 0, dp[i][0] = 0
Если x[i-1] == y[j-1]: dp[i][j] = dp[i-1][j-1] + 1
Иначе: dp[i][j] = max(dp[i-1][j], dp[i][j-1])

5. Уменьшение сложности вычисления Фибоначчи
Наивная рекурсия: O(2ⁿ) - экспоненциальная
С мемоизацией: O(n) - линейная, за счет кэширования результатов
Матричное возведение: O(log n) - логарифмическая, используя свойство линейной алгебры
