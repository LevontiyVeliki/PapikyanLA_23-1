Лабораторная работа №8: Жадные алгоритмы
Цель работы
Изучение метода проектирования алгоритмов, известного как "жадный алгоритм". Освоение принципа принятия локально оптимальных решений на каждом шаге и понимание условий, при которых этот подход приводит к глобально оптимальному решению. Получение практических навыков реализации жадных алгоритмов для решения классических задач, анализа их корректности и оценки эффективности.

Теоретическая часть
Основные понятия
Жадный алгоритм - алгоритм, который на каждом шаге принимает локально оптимальное решение в надежде, что итоговое решение будет глобально оптимальным.
Ключевые характеристики:
Жадный выбор: На каждом шаге выбирается лучший из доступных вариантов в данный момент, без учета последствий для будущих шагов.
Оптимальная подструктура: Оптимальное решение задачи содержит в себе оптимальные решения её подзадач.

Области применения
Жадные алгоритмы эффективны для задач, где выбор, сделанный на каждом шаге, не ухудшает возможности достижения глобального оптимума. Они часто работают быстро (полиномиальное время), но не всегда приводят к оптимальному решению.

Реализованные алгоритмы

Непрерывный рюкзак (Fractional Knapsack)
Алгоритм Хаффмана (Huffman Coding)
Задача о сдаче (Coin Change)

Анализ корректности жадных алгоритмов
1. Задача о выборе заявок
Жадная стратегия: Сортировка по времени окончания и выбор следующего рано заканчивающегося непересекающегося интервала.
Корректность: Доказывается методом замены. Предположим, существует оптимальное решение, отличное от жадного. Можно заменить первый отличающийся интервал в оптимальном решении на жадный выбор без ухудшения решения, так как жадный выбор заканчивается раньше и освобождает ресурс для большего количества интервалов.

2. Непрерывный рюкзак
Жадная стратегия: Сортировка по убыванию удельной стоимости (value/weight) и взятие большего количества лучших предметов.
Корректность: Если существует предмет с более высокой удельной стоимостью, который не взят полностью, то можно заменить часть предмета с меньшей удельной стоимостью на часть этого предмета, увеличив общую стоимость.

3. Алгоритм Хаффмана
Жадная стратегия: На каждом шаге объединение двух символов с наименьшей частотой.
Корректность: Доказывается через лемму о том, что два наименее частых символа должны быть соседями на самом глубоком уровне дерева. Оптимальность следует из свойства минимальной избыточности кодирования.

4. Задача о сдаче
Жадная стратегия: Выбор наибольшей возможной монеты на каждом шаге.
Корректность: Работает только для канонических систем монет, где каждый номинал больше суммы всех меньших номиналов. Для неканонических систем жадный алгоритм может давать неоптимальное решение.

5. Алгоритм Прима
Жадная стратегия: На каждом шаге добавление ребра минимального веса, соединяющего дерево с новой вершиной.
Корректность: Следует из разрезающего свойства MST - минимальное ребро, пересекающее разрез, должно принадлежать MST.

Ключевые выводы
Жадные алгоритмы эффективны для задач с оптимальной подструктурой и свойством жадного выбора
Время выполнения обычно O(n log n) из-за необходимости сортировки
Не всегда оптимальны - важно проверять условия корректности для каждой задачи
Практическое применение - от планирования до сжатия данных
Важность доказательства - без формального доказательства нельзя быть уверенным в оптимальности


Ответы на контрольные вопросы
1. Основная идея жадных алгоритмов
Основная идея заключается в принятии локально оптимальных решений на каждом шаге в надежде, что это приведет к глобально оптимальному решению. Алгоритм никогда не отменяет своих решений и работает "жадно" - выбирает наилучший вариант в текущий момент.

2. Корректность жадной стратегии для выбора заявок
Жадная стратегия (выбор интервала с наименьшим временем окончания) оптимальна потому что:
Освобождает ресурс как можно раньше
Позволяет рассмотреть максимальное количество последующих интервалов
Любое оптимальное решение можно преобразовать в жадное без потери оптимальности

3. Примеры задач
Оптимальны:
Непрерывный рюкзак
Выбор заявок
Кодирование Хаффмана
Минимальное остовное дерево
Не оптимальны:
0-1 рюкзак
Задача коммивояжера
Раскраска графа

4. Разница между непрерывной и дискретной задачами о рюкзаке
Непрерывная (дробная): Можно брать части предметов. Жадный алгоритм оптимален.
Дискретная (0-1): Предметы берутся целиком или не берутся. Жадный алгоритм не оптимален.

5. Алгоритм Хаффмана
Жадная стратегия: На каждом шаге объединять два символа с наименьшей частотой.
Оптимальность: Создает префиксный код с минимальной средней длиной, что обеспечивает максимальное сжатие без потерь. Оптимальность доказывается через свойства энтропии и информацию Шеннона.
