Лабораторная работа №6: Бинарные деревья поиска
Цель работы
Изучение древовидных структур данных, их свойств и применения. Освоение основных операций с бинарными деревьями поиска (BST). Получение практических навыков реализации BST на основе узлов, рекурсивных алгоритмов обхода и анализа их эффективности. Исследование влияния сбалансированности дерева на производительность операций.

Теоретическая часть
Основные понятия
Дерево - рекурсивная структура данных, состоящая из узлов, где каждый узел имеет значение и ссылки на дочерние узлы.

Бинарное дерево поиска (BST) - дерево, для которого выполняются условия:

Значение в левом поддереве любого узла меньше значения в самом узле
Значение в правом поддереве любого узла больше значения в самом узле

Оба поддерева являются бинарными деревьями поиска

Сложность операций
Операция	Средний случай	Худший случай
Вставка	O(log n)	O(n)
Поиск	O(log n)	O(n)
Удаление	O(log n)	O(n)
Обход	O(n)	O(n)

Ключевые особенности реализации
TreeNode класс - узел дерева с значением и ссылками на потомков

BinarySearchTree класс - основная реализация BST с методами:

insert() - вставка элемента
search() - поиск элемента
delete() - удаление элемента
find_min()/find_max() - поиск экстремальных значений
height() - вычисление высоты
is_valid_bst() - проверка корректности BST
_visualize() - текстовая визуализация дерева

Методы обхода:
Рекурсивные: in-order, pre-order, post-order
Итеративный in-order с использованием стека
Level-order (BFS) обход
