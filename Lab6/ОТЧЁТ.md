Теоретическая часть
Основные понятия
Дерево - рекурсивная структура данных, состоящая из узлов, где каждый узел имеет значение и ссылки на дочерние узлы.

Бинарное дерево поиска (BST) - дерево, для которого выполняются условия:

Значение в левом поддереве любого узла меньше значения в самом узле
Значение в правом поддереве любого узла больше значения в самом узле

Оба поддерева являются бинарными деревьями поиска

Сложность операций
Операция	Средний случай	Худший случай
Вставка	O(log n)	O(n)
Поиск	O(log n)	O(n)
Удаление	O(log n)	O(n)
Обход	O(n)	O(n)

Влияние структуры дерева на производительность
Сбалансированное дерево:

Высота растет логарифмически: O(log n)
Время поиска увеличивается медленно
Соответствует теоретической оценке O(log n)
Вырожденное дерево:
Высота растет линейно: O(n)
Время поиска увеличивается пропорционально размеру
Соответствует теоретической оценке O(n)

Ключевые выводы

Балансировка критически важна для эффективности операций BST
В вырожденном случае BST вырождается в связный список с O(n) операциями
Практические результаты подтверждают теоретические оценки сложности
Для поддержания эффективности необходимы алгоритмы балансировки (AVL, Красно-черные деревья)

Ответы на контрольные вопросы
1. Основное свойство бинарного дерева поиска (BST)
Основное свойство BST: для любого узла все значения в левом поддереве меньше значения узла, а все значения в правом поддереве больше значения узла. Это свойство обеспечивает эффективный поиск по принципу "разделяй и властвуй".

2. Алгоритм вставки нового элемента в BST
Алгоритм вставки:

Начинаем с корня дерева
Сравниваем вставляемое значение с текущим узлом
Если значение меньше - переходим в левое поддерево, если больше - в правое
Повторяем до достижения пустой позиции
Создаем новый узел в найденной позиции

Сложность:

Сбалансированное дерево: O(log n)
Вырожденное дерево: O(n)

3. Разница между DFS и BFS обходами
DFS (Depth-First Search) - обход в глубину:
In-order: левый-корень-правый (для BST возвращает отсортированную последовательность)
Pre-order: корень-левый-правый (полезен для копирования структуры)
Post-order: левый-правый-корень (полезен для удаления)
BFS (Breadth-First Search) - обход в ширину:
Посещение узлов уровень за уровнем
Использует очередь вместо стека

4. Проблема вырождения BST
При добавлении отсортированных значений BST вырождается в связный список, так как каждый новый элемент добавляется только в правое (или только в левое) поддерево. Высота дерева становится O(n), а операции поиска и вставки деградируют до O(n).

5. Сбалансированные деревья (AVL)
Сбалансированные деревья (AVL, Красно-черные) автоматически поддерживают балансировку с помощью поворотов. Они гарантируют, что высота дерева остается O(log n), обеспечивая время операций O(log n) даже в худшем случае.
